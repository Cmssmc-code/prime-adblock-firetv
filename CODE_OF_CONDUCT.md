# Code of conduct

We want this to be a friendly, useful place for people who like understanding how things work.

* Be respectful and patient. Assume good faith; many contributors are learning.
* Criticise code and ideas, not people. No harassment, personal attacks, or discrimination of any kind.
* Keep discussions on topic: reverse engineering, testing and documenting this hook.
* Do not use the project to share pirated content, account credentials or ways to bypass payment. This project is about the
  ads in a service you already have access to, nothing else.
* Do not post Amazon's code or binaries, or anyone's private data.

Maintainers may edit, hide or remove comments, issues and PRs that break these rules, and may block repeat offenders.
Report problems by opening a private security advisory on the repository or by contacting the maintainer through their
GitHub profile. This text is a short adaptation of the spirit of the Contributor Covenant.
